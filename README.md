# Neutronz Company Brain

> **Every agent action traces through a graph path back to the SOP, the decision, and the person behind it — and every claim in this file is a number you can re-run.**

Neutronz ingests scattered company knowledge (SOPs, email, Slack, Drive, uploads), turns it into a **per-tenant FalkorDB knowledge graph**, and lets AI agents **answer questions and do real work** — freight screening, invoice approvals, email triage — by walking that graph. Every answer ships with a **Decision Trace** (exact graph path + source snippets), a **tamper-evident ledger**, **precedents and absence proofs pulled from the graph**, and a **before/after simulation** of any rule change before a human applies it.

Built for **Graph Hacks: Context for AI Agents** (FalkorDB x WeMakeDevs).
